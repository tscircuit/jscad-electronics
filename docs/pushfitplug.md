# PushFitPlug

`pushfitplug_tubeod6mm_l18mm_headod10mm_headt3mm`

Solid round push-in tube stopper with an integral flat extraction head. Overall length includes the head. Shaft axis is +Z; insertion tip Z=0, shoulder Z=length-headThickness. No seal or pressure rating implied.

Schemas, units and validation come from modelprinter. Public factories are `createPushFitPlugGeom` and `createPushFitPlugMesh`; React component is `PushFitPlug`. Mechanical models produce no copper pads. Circular profiles use 64 segments (holes use 48). Fillets use 16 segments per quadrant. These meshes model nominal geometry without manufacturing tolerances.
